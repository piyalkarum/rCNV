# Normalized allele depth example data

Normalized example SNPs data of Chinook Salmon from Larson et al. 2014
The data has been normalized with TMM

## Usage

``` r
data(ADnorm)
```

## Format

An object of class `list` of length 2.

## References

Larson, W. A., Seeb, L. W., Everett, M. V., Waples, R. K., Templin, W.
D., & Seeb, J. E. (2014). Genotyping by sequencing resolves shallow
population structure to inform conservation of Chinook salmon
(Oncorhynchus tshawytscha). Evolutionary Applications, 7(3)
